## Сделано

### Исправления

- [x] **Превью открывалось в нижнем левом углу экрана.**
      Точка привязки бралась из `panel.frame` до `makeKeyAndOrderFront`, то
      есть из нулевого фрейма только что созданной панели. Теперь считается
      от центра рабочей области экрана активного окна.
      Проверено замером: панель `(896, 560)`, центр экрана `(896, 560)`.

- [x] **Свайп-навигация подтормаживала.** Три причины:
      кадры выдавались по `Timer` без привязки к вертикальной синхронизации;
      размытие по Гауссу считалось синхронно в главном потоке дважды на
      навигацию; инерция трекпада гасилась по таймауту 0.12 с, хотя
      momentum-события идут секунду-две, и остаток уводил сетку вбок под
      оверлеем.

- [x] **Волна не укладывалась в кадр на интегрированной графике.**
      Медиана времени `updateLayer` была нулевой — вызовы массово выходили
      по проверке `renderInFlight`, кадры отбрасывались. Волна считается в
      0.65 размера окна (выбор по `MTLDevice.isLowPower`).
      Замер: дрожание упало с 15–18 мс до **2.2–3.7 мс**, 95% кадров легли
      ровно в 16.7 мс — шаг вертикальной синхронизации 60 Гц.

- [x] **Мерцание яркости и насыщенности на краях перехода.** Две причины:
      кадры волны рендерились в sRGB и выводились без цветокоррекции прямо
      на профиль матрицы; снимок окна снимался в `calibratedRGB` и делал
      лишний круг конверсий, которого живая сетка не делает.

- [x] **Photoshop предлагался для видео.** Пункт показывается, только если
      приложение откроет всё выделенное.

- [x] **Подпись плитки обрезалась у видео.** Из четырёх частей строка не
      влезала. Тип убран там, где известно разрешение: расширение и так
      видно в имени файла.

### Возможности

- [x] **«Ресайз» в контекстном меню.** Пресеты 5999/4096/2560/2048/1024 и
      свой размер. Через `sips`, пропорции сохраняются, оригинал не
      трогается, результат `<имя>_maxN` рядом, коллизии имён дают `_1`.
      Проверено сквозным прогоном: 6601×2801 → 5999×2545.

- [x] **Разрешение и длительность в сетке.** Одной строкой, без роста
      высоты плитки. Поворот видео учитывается. Чтение в фоне с кэшем.

- [x] **Отметки «отобрано».** На настоящих метках Finder: переживают
      перемещение и переименование, видны в Finder, индексируются Spotlight.
      Отдельная ось от цветных меток, не конфликтуют.

- [x] **Разбор пачки в Quick Look.** `⌫` в корзину с переходом к следующему
      кадру, `F` отметить. Удаление пишется в историю операций — отменяемо.

- [x] **Отметка мышью в сетке.** Звёздочка в углу плитки: у отмеченных
      всегда, у остальных проявляется под курсором. Ячейка забирала все
      клики на себя ради выделения и перетаскивания — звёздочка сделана
      единственным исключением в `hitTest`.

- [x] **Счётчик `★ сегодня` в статусбаре.**

- [x] **Photoshop и Premiere Pro** отдельными пунктами меню с иконками.

## Утверждено, в работе

- [x] **Свой просмотрщик вместо системного Quick Look.** Готов в первой
      версии. Построен на `QLPreviewView`, поэтому поддержка форматов
      осталась полной. Есть: значок отметки внутри кадра, сравнение
      двух-трёх панелей, клавиши (стрелки, `F`, `⌫`, `C`, `Esc`), подпись
      с разрешением и весом, строка подсказок, стиль проводника.
      Проверено: `F` пишет метку, Spotlight её находит.

- [x] **Кнопка «на весь экран» в просмотрщике.** Зелёная кнопка окна и
      клавиша `T` растягивают окно на видимую область экрана и возвращают
      обратно. Системный полноэкранный режим перехвачен: он уводил окно на
      отдельный рабочий стол и мешал перетаскивать файлы в проводник.

- [x] **Неактивная панель перезагружала кадр.** `show(url:)` пересоздавал
      `QLPreviewView` при каждом обновлении, даже если файл не менялся, и
      соседние панели мигали при листании активной. Теперь кадр не
      трогается, если файл тот же.

- [x] **Режим сравнения переживал закрытие окна.** Число панелей хранилось
      в контроллере, и следующий пробел открывал сразу пачку. Каждый показ
      начинается с одной панели.

- [x] **Левая панель не меняла ширину.** Ей был выставлен обязательный
      приоритет удержания (`setHoldingPriority(.required, forSubviewAt: 0)`),
      то есть «ширина не меняется никогда» — разделитель тянулся, но
      `setPosition` тут же отменялся. Приоритет снижен до 260: ширина
      сохраняется при изменении размера окна, но ручка работает. Диапазон
      расширен с 244–360 до 200–560.

- [x] **28 копий Qyvro в поиске и Launchpad.** Это бэкапы в
      `FPilotMac_Backups` и в дубле проекта `CODEX_PRJ_copi`, а не
      установленные приложения — установлена ровно одна копия в
      `~/Applications`. Файлы не тронуты: папки помечены
      `.metadata_never_index`, бандлы сняты с регистрации в LaunchServices.

- [ ] **Поиск выдаёт много системного мусора.** Отфильтровать служебные и
      кэшевые пути, показывать только осмысленные файлы.

- [ ] **Выбор файла в проводнике меняет кадр в открытом просмотрщике.**
      Просмотрщик остаётся открытым, переключаешься в проводник, выбираешь
      другой файл — он подставляется в просмотрщик. В режиме сравнения
      подставляется в ту панель, которая выделена.

- [ ] **Режим шторки.** Два кадра наложены друг на друга, между ними
      подвижная вертикальная граница: тянешь её мышью и видишь, где
      варианты расходятся. Это отдельный режим рядом с панелями «рядом».

- [ ] **Просмотрщик открывается дольше 4 секунд.** `QLPreviewView`
      пересоздаётся под каждый файл, и для тяжёлых кадров (25 МБ,
      5504×3072) это заметно. Для разбора пачки, ради которого всё
      затевалось, это блокирующая проблема: листание стрелками должно быть
      мгновенным.
      Что делать: не пересоздавать `QLPreviewView`, а переиспользовать один
      экземпляр со сменой `previewItem`; заранее готовить соседние кадры;
      показывать миниатюру из кэша сетки, пока грузится полный кадр.

- [ ] **Перетаскивание с конвертацией по клавише ⌥.**
      Обычное перетаскивание отдаёт оригинал, с зажатым ⌥ — JPEG до 5999
      по длинной стороне и до 20 МБ (лимиты Seedance). Файл готовится во
      временную папку в момент начала перетаскивания, поэтому работает с
      любым получателем: браузер, Фигма, Телеграм.
      `fn` рассматривалась и отклонена: на этой машине она назначена на
      диктовку (`AppleFnUsageType = 3`).

## Известные проблемы

- [ ] **Первый свайп после запуска замирает на ~960 мс.** Core Image
      компилирует шейдер в этот момент. Прогрев в коде есть, но не
      срабатывает. Проверены и опровергнуты замером две гипотезы:
      форма графа и размер прогрева. Остаётся третья — цветовое
      пространство входных картинок прогрева.

- [ ] **Мёртвый код.** `CompositorSwipeSurfaceWaveView` (~450 строк) не
      используется нигде. Оставлен автором как запасной вариант эффекта.

- [ ] **`FilePanel.swift` разросся до 4700 строк.** Тяжело поддерживать.

- [ ] **Буфер обмена опрашивается таймерами** каждые 0.55 с и 1 с — расход
      батареи на ноутбуке.
