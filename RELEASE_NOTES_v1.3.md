# Qyvro 1.3 — Universal Release

Qyvro — файловый менеджер для macOS с вкладками, быстрым предпросмотром,
историей операций, встроенным буфером обмена и AirDrop-подобной навигацией.

## Новое в 1.3

- Глобальное `⇧⌘V` открывает встроенную историю буфера Qyvro отдельным
  плавающим окном поверх текущей программы. Скрытый проводник при этом не
  появляется и активная программа не меняется; повторное `⇧⌘V` закрывает
  только окно буфера. Обычная вставка по `⌘V` не затронута.
- Вкладки теперь сначала плавно ужимаются сами и не выдавливают левую панель.
  После создания новых вкладок подписи, иконки и заголовки сайдбара сохраняют
  стабильные внутренние отступы.
- Quick Look меняет размер окна под разрешение каждого изображения или видео,
  сохраняя окно в пределах текущего экрана. Одинаковые и близкие разрешения
  не запускают лишнее изменение геометрии, а центр окна не дрейфует. Сам размер
  применяется одним кадром без тяжёлой анимации окна, поэтому листание
  закэшированных изображений не притормаживает.
- Стрелки в Quick Look листают соседние элементы сетки. Все уже открытые
  изображения — не только два ближайших — остаются в собственном сессионном
  кэше Qyvro и повторно появляются без загрузки. Кэш полностью очищается при
  закрытии предпросмотра; предзагрузка соседей не конкурирует с текущим файлом.
- Двойной клик по верхней панели Quick Look разворачивает предпросмотр на весь
  экран. В полноэкранном режиме можно продолжать листать всю текущую подборку
  стрелками без сброса кэша; `Esc`, повторный двойной клик или `⌃⌘F` возвращают
  обычное окно предпросмотра.
- Поиск «Mac» использует Spotlight и находит совпадения не только в имени, но
  и в индексируемом содержимом документов.
- Цветовые метки Qyvro теперь являются настоящими тегами Finder: они видны в
  обеих программах, а уже существующие внешние теги не перезаписываются.
- AirDrop добавлен прямо в контекстное меню выбранных файлов и папок.
- Именованные группы вкладок сохраняются между запусками. Группу можно открыть,
  добавить к текущим вкладкам, обновить или удалить.
- Быстрые свайпы назад/вперёд запускают независимые волны одинаковой скорости:
  новые гребни идут следом за предыдущими, не ускоряя их и не ожидая очереди.
- Обновлена анимация и hover-состояния кнопок верхней панели.
- Исходный код разделён на независимые модули; `main.swift` теперь отвечает
  только за запуск приложения.
- Проведена техническая уборка: удалены старые debug/QA-артефакты, сокращены
  унаследованные импорты модулей и упрощён build-скрипт. Метаданные видео для
  Quick Look теперь читаются современным асинхронным AVFoundation без
  блокировки главного потока.

## Уже включено

- одно окно Qyvro и полноценные вкладки с перетаскиванием;
- перенос файла через наведение на другую вкладку;
- сохранение позиции скролла и выделения отдельно для каждой папки;
- MP4-превью, панель свойств, размеры файлов и подсчёт размера папок;
- HEIC → PNG и PNG → JPEG из контекстного меню;
- undo/redo файловых операций;
- глобальный ⌘E, вызывающий единственное окно на текущий рабочий стол;
- режим «поверх всех окон»;
- встроенная история буфера обмена;
- Universal binary: Intel x86_64 и Apple Silicon arm64.

## Системные требования

- macOS 13 Ventura или новее.
- Intel Mac либо Apple Silicon: M1, M2, M3, M4 и последующие совместимые
  процессоры arm64.

## Первый запуск

Сборка подписана локальной ad-hoc подписью, поскольку для проекта пока не
подключён сертификат Apple Developer ID.

1. Перетащите `Qyvro.app` в папку «Программы».
2. Нажмите по Qyvro правой кнопкой мыши и выберите «Открыть».
3. Подтвердите запуск.

После этого приложение открывается обычным способом. Для установки без
предупреждения при первом запуске потребуется Developer ID и нотариализация
Apple.
