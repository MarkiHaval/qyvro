# Qyvro 1.1

Universal-сборка для macOS 13 и новее: Intel (`x86_64`) и Apple Silicon
(`arm64`, включая M1–M4) находятся в одном приложении.

## Главное

- Глобальное сочетание `⌘E` вызывает уже открытое окно Qyvro на текущий рабочий
  стол. Новый экземпляр приложения не создаётся.
- Служебные окна копирования и переноса больше не должны переключать macOS на
  другой рабочий стол и не забирают клавиатурный фокус.
- Добавлены реальные безопасные `⌘Z` и `⇧⌘Z` для переноса, копирования, замены,
  переименования и Корзины.
- Исправлен цветовой скачок и Retina-качество кадров wave-анимации.
- Добавлены новые анимации интерфейса и пресеты «Qyvro Aurora» /
  «Глубокий космос».
- Перед каждой сборкой автоматически создаётся проверенный архив исходников.

## Установка

1. Распакуйте архив и перенесите `Qyvro.app` в папку «Программы».
2. При первом запуске нажмите по приложению правой кнопкой мыши и выберите
   «Открыть». Сборка подписана локальной ad-hoc подписью, но пока не
   нотарифицирована через Apple Developer.
3. Если macOS всё равно блокирует первый запуск, выполните:

   ```bash
   xattr -cr /Applications/Qyvro.app
   ```

## Безопасность отмены

Qyvro не перезаписывает новый файл ради Undo. Если после операции целевой путь
уже занят или отключён внешний диск, отмена останавливается и показывает ошибку.
