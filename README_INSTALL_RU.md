# Установка Qyvro 1.3

1. Распакуйте архив.
2. Перетащите `Qyvro.app` в папку «Программы».
3. При первом запуске нажмите по приложению **правой кнопкой → Открыть**.
4. Подтвердите запуск в системном окне macOS.

Qyvro 1.3 собран как Universal-приложение и содержит обе архитектуры:

- `x86_64` — Intel Mac;
- `arm64` — Apple Silicon: M1, M2, M3, M4 и следующие совместимые поколения.

Минимальная версия системы — macOS 13 Ventura.

Если macOS всё равно блокирует запуск, откройте:
**Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.
